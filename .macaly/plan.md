# 복합 견적 기능 추가

## 개요
안전방충망, 유리난간, 후퍼옵틱 중 2개 이상 상품을 한 견적서에 합산할 수 있는 기능 추가.

## 동작 방식

1. **기존 흐름은 그대로 유지** — 각 상품의 선택 단계는 변경 없음
2. **결과 페이지에 "다른 상품 추가" 버튼 추가** — 현재 견적을 저장하고 처음 선택 화면으로 이동
3. **처음 선택 화면에서 이미 추가된 상품 표시** — 취소(삭제)도 가능
4. **결과 화면에서 합산 견적 표시** — 각 상품별 소계 + 전체 합산 총액으로 카드 혜택 계산
5. **복사 텍스트도 전체 합산**으로 출력

## 구현 단계

- [ ] `CompletedQuote` 타입과 `completedQuotes` 상태 추가
- [ ] 각 결과 페이지(안전방충망/유리난간/후퍼옵틱)에 "다른 상품 추가" 버튼 추가
- [ ] 버튼 클릭 시 현재 상품을 `completedQuotes`에 저장 후 단계 1로 이동
- [ ] Step 1 화면에 추가된 상품 목록 표시 (삭제 버튼 포함)
- [ ] 결과 화면에 `completedQuotes` 소계 + 현재 상품 소계 → 전체 합산 표시
- [ ] 복사/공유 텍스트에 전체 합산 내역 반영
- [ ] "처음으로" 버튼 클릭 시 completedQuotes도 초기화

## No-gos
- 각 상품의 개별 선택 단계 UI는 변경 없음
- 동일 상품을 2개 추가하는 것도 허용 (예: 안전방충망 두 세트)
